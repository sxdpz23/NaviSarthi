# NaviSarthi 0.6.0 integration

The user approved prototype revision 7, including deeper glass/refraction, the Settings label, and the helmet-intercom Groups icon. The native implementation is integrated and the release APK has been built. Device and hardware acceptance remain outstanding as described below.

## Application structure

Navigation is source in `app/src/main/java/com/sxdpz23/navisarthi/navigation`, with resources and assets in the application's existing source set. It is not a second Android application or library app. NaviSarthi owns the Application, Activity, manifest, dependency injection, intents, service declarations, version, and Settings entry. The only additional Gradle project, `navigation-runtime`, relocates the protobuf classes in the OsmAnd Java dependency; it has no Android application or UI.

The app remains `com.navisarthi.app`, version `0.6.0` (31). Upstream APK checks are disabled. NaviSarthi's existing update controls remain the app update owner. Navigation's old About/updater screen is now a map-data and license page. Published map/runtime data endpoints and third-party notices retain their actual provider identities.

## UI and preserved entry points

| Tab | Content |
| --- | --- |
| Dash / Pod | Vehicle-specific console view, connection and preferences; console route editor |
| Nav | Map, search, routes/stops, places, traffic/transit, offline maps, voices, saved places and navigation |
| Garage, optional | Maintenance/checks, fuel diary and Glovebox |
| Groups | Feature coming soon; filled helmet with external intercom microphone |
| Settings | Existing app/console settings, navigation settings, Ride History |

The floating Compose bar captures the content behind it, applies a background-only AGSL refraction/blur effect, and keeps icons/text sharp. It uses a shared spring selection lens, neutral rim highlights/shadows, vehicle accent, scroll collapse, and directional page transitions. Compose's animator duration scale controls reduced motion. Compact height is 60dp with at least 48dp touch targets. Map controls reserve space while the texture-backed map extends under the glass.

Top-level tab changes save/restore navigation state. The map ViewModel belongs to the single Activity, retaining navigation state between tabs. Maps shares and shortcuts reach the same map ViewModel. The retained console route editor supports existing destinations/itineraries and active-journey additions.

## Navigation integration

The imported app/core source includes offline routing/downloads, map styles/data, places/search, Google-free operation, transit, traffic, voice libraries/recognition, saved lists, trip recording/replay, privacy/diagnostic options, Android Auto and PiP. These are retained as code, not replaced with a map mockup. Their runtime behaviour still needs device validation.

The Drive route adapter transfers geometry, stops, traffic duration and maneuver progress to Dash/Pod. Car rerouting uses the integrated map data source and its avoidance/privacy options. The existing motorcycle route provider remains available in the console editor. Sending a route to a console stops phone navigation first; starting phone navigation ends active console guidance. This does not establish hardware acceptance or identical guidance behaviour on a physical console.

## Toolchain and verification

- AGP 9.4.1, Gradle 9.8.0, Kotlin 2.4.20, compile SDK 37.0, Java bytecode 17. Target SDK remains 36; minimum SDK remains 34.
- MapLibre OpenGL 13.6.1 is shared by phone and console rendering. The old annotation plugin excludes its older renderer dependency.
- `python scripts/fetch-navigation-runtimes.py` retrieves and SHA-256 verifies the pinned OsmAnd, XML, Cronet and sherpa-onnx dependencies into ignored `app/libs/navigation/`.
- This checkout has a locked legacy `app/build` directory. Verification uses an isolated `.build-v060` output via the local Gradle init file in `.superdesign/tmp/v060/build.init.gradle`.
- Final verification: release assembly passed; 127 JVM tests across 27 suites passed with no failures, errors or skips. Runtime dependency hashes and source whitespace checks passed. APK identity/signature were checked separately.
- Local APK: `version 0.6.0/NaviSarthi-0.6.0.apk`; version 0.6.0 (31), application ID `com.navisarthi.app`, arm64-v8a. SHA-256: `4a0d6562f0321dbd6c016e77728906df7707ff3be031a8dbba235ffd55c5d309`.
- No Android device or emulator was connected. Glass rendering, lifecycle/PiP, accessibility, online/offline providers, downloads, Android Auto and physical Dash/Pod handoff/rerouting require device checks. Do not infer runtime feature parity from compilation or JVM tests.
