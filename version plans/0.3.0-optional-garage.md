# Optional Garage

Settings > App features includes an Enable Garage toggle, off by default for existing and new installs without a stored choice. Persist the choice locally across launches.

Hide the Garage bottom tab and prevent its screen from opening while disabled, including when restoring a back stack. Keep saved records when hiding Garage; re-enabling restores access. The remaining bottom tabs share the available space.

Check fresh install, enable/disable, process restart and restored navigation. No APK/version increment requested.
