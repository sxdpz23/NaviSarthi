## Display-only traffic pilot

Dash offers an opt-in overlay using TomTom raster flow tiles. Enter a Traffic API key on the phone. The app fetches tiles over a validated internet connection, clips the overlay to a narrow band along the visible active route, expires tiles after three minutes, and caps the phone at 180 requests per day. The normal route stays visible when tiles are unavailable. The tile overlay can include traffic on close parallel roads and does not recalculate routes or ETAs.

Test in India with an authorized key, the dash Wi-Fi connected, and mobile data enabled. Confirm the overlay, attribution, switch-off, loss of connectivity, invalid-key handling and no traffic requests in fixed offline navigation.

### Traffic controls and legend

Dash explains the three-minute refresh, shows the TomTom relative0 colour legend, and links to the official API key setup instructions. Black with Golden Line disables the switch and suppresses the overlay and new tile requests. Leaving that combination restores the user's prior traffic preference.
