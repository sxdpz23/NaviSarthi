# Live ETA using journey average speed

Divide remaining active-leg distance by the measured whole-navigation average speed up to the current moment. Use validated GPS speed integration and monotonic elapsed session time, including stops. Preserve the average across intermediate stops and reroutes, and reset it for a new journey or navigation exit.

Update the displayed estimate every five seconds. Do not apply a minimum speed or use the Car/Bike planning averages in live navigation. Show no ETA until motion has been measured. Pre-journey estimates remain 50 km/h Car and 60 km/h Bike. GPS gaps can undercount movement and make ETA less accurate. No APK/version increment requested.
