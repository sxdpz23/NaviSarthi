# NaviSarthi 0.5.0 — Offline and reusable rides

Status: Planned

## Focus

Add downloadable regions and explicit offline routing capability subject to provider licensing. Save named custom routes and ordered stops; distinguish exact track following from recalculated routes. Add local ride history and export.

## Acceptance

Test airplane/no-data navigation, missing regions, interrupted downloads, storage limits, saved-route reload and history persistence. Define route import format and offline engine before implementation.

## Evidence and decisions

Not yet implemented/verified for this milestone. Record implementation results here; resolve provider/hardware decisions before the affected work.

## Offline navigation options

- Fixed-route download is the current option. Download a planned itinerary with its route legs and turn instructions, then follow it offline.
- Regional download is a future option alongside fixed routes. Download an area first, then choose destinations and calculate or reroute multi-stop journeys offline inside its coverage. Validate the map package, local routing, and motorcycle access before release.
