# Ride statistics correction

Previously average speed used coordinate distance / session duration, while maximum used GPS speed only at thinned track points. GPS drift and missed peaks could produce an average above maximum.

Integrate validated GPS speeds using monotonic fix timestamps for distance. Capture maximum on every valid sample, independently of track thinning. Average includes the entire connection session and stopped time. Reject stale/pre-session fixes, invalid speeds and poor accuracy; do not extrapolate across gaps over five seconds. Distance can undercount when GPS speed is unavailable or reception is lost.

Keep old stored records intact. Mark inconsistent speed statistics unavailable in ride cards and shared images; do not invent corrected historical values. No APK/version increment requested.

Verify constant speed, stopped time, brief peaks, duplicates, invalid samples, stationary noise and GPS gaps with unit tests. Real ride comparison against the odometer remains necessary.
