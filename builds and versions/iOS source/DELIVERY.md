# NaviSarthi iOS source delivery

Expanded native iOS implementation prepared on Windows on 2026-11-19.
Extract the ZIP, open iOS/NaviSarthi.xcodeproj on a Mac, and follow iOS/README.md.

Source includes native regional offline road routing/rendering, traffic and GPX,
Garage/rides, Android backup import and automatic collection sync with conflicts,
Google OAuth/Drive, Share Extension, Comms/conditional audio and Dash/Pod adapters.
Public Music/call-state controls and experimental iOS 26 projection are included.
SDKs, extension embedding, OAuth/APNs and branding helpers require receiving-Mac setup.
This is not complete Android parity. See iOS/docs/PARITY.md.

See VERIFICATION.json for grammar checks. Structural checks and ZIP integrity passed. Compilation, tests, signing,
simulator and hardware validation were not run. No IPA has been produced.
