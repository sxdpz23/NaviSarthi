# NaviSarthi iOS source delivery

Expanded native iOS implementation prepared on Windows on 2026-11-19.
Extract the ZIP, open iOS/NaviSarthi.xcodeproj on a Mac, and follow iOS/README.md.

Source includes structured routing, traffic overlays, GPX/offline route guidance,
Garage documents/expenses/reminders, Android/local backup import, cloud backup,
Comms realtime/location/QR/admin and conditional LiveKit audio, plus Dash/Pod adapters.
This is not complete Android parity. See iOS/docs/PARITY.md.

Swift grammar, structural checks and ZIP integrity passed. Swift/Xcode compilation, tests, signing,
simulator and hardware validation were not run. No IPA has been produced.
